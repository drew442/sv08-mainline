OS IMAGES & UPDATES

Updates

Keep the running release while preparing its replacement. Installing, choosing the next boot and restarting are separate steps.

Automatic updates

Download trusted releases, install while idle, then restart and check the new release. Opting out before restart is requested leaves an armed update available for the next boot.

Advanced automatic update checks

Trusted release signatures, image integrity, safe storage layout and printer idle admission are always required.

Allowing replacement of a customized image does not carry its installed software into the new OS. Persistent printer settings and the running fallback are preserved.

Install an update manually

Use a signed OS bundle from a publisher you trust. Your running image and persistent user files are preserved.

  1. Upload & authenticate the manifest
  2. Review installation & verify the full image
  3. Choose the next boot; restart separately

1. Upload a signed bundle

Upload checks the signed manifest and stores the bundle. It does not install the image or verify its full payload.

Advanced checks for this manual update

These choices apply only to the upload or staging you review. Image integrity, physical layout, recovery and idle admission remain required.

Check the publisher yourself before accepting an untrusted signer. The bundle must still have a valid cryptographic signature and verity payload; malformed or signature-free files cannot be installed.

RECOVERY

Recovery guidance

The independent recovery screen is designed to work when the normal OS images cannot start. This web page provides guidance.

Recovery boot entry is not enabled here

Recovery boot entry and storage repair require the completed board recovery image. This candidate does not enable them.

Use only the reviewed boot procedure for the exact board and recovery image. This page cannot start recovery or restore an OS.

Preserve what you need

Before replacing an image, save readable configuration and user files to a USB drive. Recovery never formats user data as part of an OS restore.

Printer identity has its own private backup. It does not include account passwords, network settings or printer calibration.

At the independent recovery screen

  1. Start the recovery system using the reviewed boot procedure.
  2. Choose a preserved system or a signed replacement image.
  3. Review the target and confirm. Your user data is preserved.
Touch, keyboard & mouse controls

Touch the large buttons, or use Tab, Shift+Tab and Enter. Escape cancels a confirmation. A mouse works too.
