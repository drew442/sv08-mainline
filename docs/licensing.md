# Licensing and attribution

Original project code and documentation use **AGPL-3.0-or-later**, as declared in
the authoritative [project grant](../LICENSING.md); see [LICENSE](../LICENSE) for
the full terms. Third-party material retains its own terms. The grant also defines
the public matching-source release policy.

Each submodule retains its own license and file-level notices. Consult the pinned
checkout before redistributing code, firmware, images, or copied documentation.
Keep provenance and applicable notices with any derivative patch or configuration.
Linked datasheets remain their publishers' material; the reference index does
not relicense them.

Release builders must run the [public matching-source qualification gate](development/public-source-releases.md) against the final installed root. A source-only receipt is not an overall image or redistribution-compliance qualification.
