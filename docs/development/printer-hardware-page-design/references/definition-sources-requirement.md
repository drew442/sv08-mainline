# Owner requirement — creator-published definition sources

Added to the design discussion on 6 October 2026. Verbatim user message:

> i'd like the upgrade/add-on creator and other third parties be able to contribute definitions easily. my thought for this would be by defining an extensible schema that we can publish for others to use when creating their definition. then the upgrade/add-on creator can publish their definition, or collection of definitions, to a github repository. the user can then add a creator's repo to sv08-mainline and use those definitions on the printer hardware page in addition to any 'built-in' definitions that we create.
