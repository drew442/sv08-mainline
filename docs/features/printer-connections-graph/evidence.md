# Printer connections graph delivery

Owner-authorized standalone `#printer-connections` main-menu page replaces the hardware Connections tab. Shared session, draft and saved revision remain the existing model. HTML nodes and SVG wires use browser-local fixed geometry, pan, zoom, fit, reset, draggable headings, keyboard controls, filtering and path highlighting. Equivalent table supports keyboard inspection and responsive use. Inspector only changes compatible documented connector choices in the unsaved draft and is authority/busy/reconcile/diagnostic gated, including its callback. Hardware provides save/review/reconciliation.

All 24 factory devices, both controllers and host transport are represented (27 nodes). Every electrical field, display/accelerometer software SPI, encoder/click input, fan tachometer and motor connector appears. Motor step/direction/enable/UART pins are inspectable. Internal MCU temperature and semantic heater/sensor references are explicitly distinguished from external electrical wires. No physical contact, orientation or private controller identity is invented/displayed.
