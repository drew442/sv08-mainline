# Definitions catalogue browser acceptance

Standalone `#definitions` left-menu route, sharing the existing document/session/draft. Source/category toggles show compact group cards and counts; group drill-down shows definition names/version/source/status. Definition details drill into embedded components or exact pinned dependencies. Settings/connections are viewed only at component level; compatibility, variant inputs, printer settings, calibration, board mappings, provenance and the full public record remain expandable disclosures. Search accepts names, IDs, aliases, source and category. Back/breadcrumb/keyboard routes preserve the group and allow stepwise return.

Records come from the existing status cache only: 25 built-ins, all imported supported records including disabled sources, plus unsupported manifest entries and their recorded reason. Source-qualified IDs prevent publisher conflation. Dependency links require source, version and the backend-provided canonical content digest; disabled cached records without that digest can be viewed individually, while pinned dependency links remain unavailable. Removed subscriptions leave the catalogue but preserved hardware snapshots retain their existing offline behavior. No new backend operation or polling is introduced; browsing has no selection/save/apply/source mutation action.
