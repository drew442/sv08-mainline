# Owner request — simpler printer hardware configuration

2026-10-05. Direct owner request in the project conversation.

Make the Cockpit printer hardware page simple for end users: choose the mainboard,
toolhead board, heated bed and hotend upgrades, and optional enclosure fan/chamber
heater. Named supported products should fill in their configuration settings.
The Funssor CN3D heated bed kit is the explicit example. PID calibration is a later
operation, not a prerequisite for hardware configuration. Select the installed
sensor and its replacement type, including NTC to PTC. Custom calibration curves
and non-default input bias belong under advanced settings.

Preserve the existing separate inactive-candidate and physical activation boundary.
Unknown product variants, connections and electrical/temperature settings cannot
be inferred from related hardware. Request the exact models/connections needed to
finish unsupported product presets; do useful source development in parallel.
