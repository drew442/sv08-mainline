## Limits

This is software configuration and simulated-MCU evidence, not named-hardware printing release. MCU firmware, electrical matching, motion polarity, probe calibration and physical thermal/motion commissioning remain separate. Fixed host paths assume the existing pinned SV08 Mainline applications/OS. Export supplies host configuration files without activating services. The ZIP includes private instance MCU identities and must not be published. Consequential installed asset overlay is assessed separately; this offline feature uses self-validation.
