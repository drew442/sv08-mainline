# Cockpit software management

Complete the Software page using a small supported Debian utility catalog and APT rather than a parallel package manager. Offer dependency/download/storage preview and reviewed durable install/remove jobs, explicit service enablement and customization manifest/report export. Require actual writable mode and atomic idle admission; protect core printer/boot/access packages and retain conffiles/user artifacts. Record versions, repository provenance and service changes privately. Preserve image-update customization blocking and explain conflicts rather than clearing customization or blindly replaying packages. No live printer package/mode/reboot change is required: validate actual package execution in a disposable system. Bounded installation of the controls may preserve the existing diagnostic configuration, identity, access and network.

Acceptance: backend failure/concurrency/state/space/customization checks; actual APT install/remove and service/reconciliation execution in disposable Linux; browser authority/loading/preview/review/job/resume/conflict/stale-response checks; staged runtime/catalog/systemd integration; full diff and publication. Physical power-loss and printing release qualification remain separate.
