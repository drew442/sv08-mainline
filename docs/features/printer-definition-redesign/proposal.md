# Definition-driven printer hardware redesign

Implement the accepted page and public source designs in the existing Cockpit shell.
Deliver cards/details, logical connections, semantic/file review, migration and
scoped overrides; a shared draft public contract, creator tooling, pinned GitHub
source lifecycle and offline composition; managed output ownership, recoverable
configuration publication and commissioning handoff. Preserve existing capabilities,
unknown hardware facts, state/revision/privacy protections and unrelated files.

All source/offline acceptance is self-validated. Consequential installed publication
is gated separately at execution. Inactive output alone does not complete the goal.
Specific source gaps remain explicit and must not be replaced with guessed values.
